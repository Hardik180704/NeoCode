# Support

NeoCode is maintained as an open-source project. Please choose the channel that
best matches your request so maintainers and contributors have enough context to
help.

## Bugs

Open a bug report using the repository issue template. Include the NeoCode
version, operating system and architecture, installation method, reproduction
steps, and sanitized terminal output.

## Feature ideas

Use the feature-request template and explain the underlying workflow or problem.
Focused proposals with examples or mockups are easier to evaluate.

## Security

Do not report vulnerabilities in a public issue. Follow the private process in
[SECURITY.md](./SECURITY.md).

## Questions

Check the [README](./README.md), [development guide](./docs/DEVELOPMENT.md),
existing issues, and closed issues first. If the answer is still unclear, open a
bug report only when behavior appears incorrect; otherwise open a focused issue
that explains what documentation is missing.

Support is provided on a best-effort basis. Never post API keys, access tokens,
private source code, database URLs, or personal information.
